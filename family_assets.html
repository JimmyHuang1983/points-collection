將部署好的家庭資產 GAS 網頁應用程式網址貼在這裡（之後每次開啟頁面會自動在背景同步）：

查看家庭資產專用 Google Apps Script 程式碼（點此展開與複製） 
function doGet() {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  // 若你的分頁名稱不是「家庭資產」，請將下方改成實際分頁名稱
  var sheet = ss.getSheetByName("家庭資產") || ss.getActiveSheet();
  var lastCol = sheet.getLastColumn();
  var lastRow = Math.min(sheet.getLastRow(), 35);
  var values = sheet.getRange(1, 2, lastRow, Math.max(1, lastCol - 1)).getDisplayValues();
  return ContentService.createTextOutput(JSON.stringify(values))
    .setMimeType(ContentService.MimeType.JSON);
}
