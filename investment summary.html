同步 Google Sheet 持股資料

支援自動辨識標題列欄位，買賣股票後可一鍵更新儀表板

支援 A4:Z105 整塊貼上

在你的 Google Sheet 選取 A4:Z105（建議包含標題列）按 Ctrl+C，貼到下方並點擊「解析並更新」。

將部署好的 Apps Script 網頁應用程式網址貼在這裡（之後按右上角「一鍵雲端同步」即可自動抓最新資料）：

查看 Google Apps Script 部署程式碼（點此展開與複製） 
function doGet() {
  // 建議將 "工作表1" 改為你實際的分頁名稱
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var values = sheet.getRange("A4:Z105").getDisplayValues();
  return ContentService.createTextOutput(JSON.stringify(values))
    .setMimeType(ContentService.MimeType.JSON);
}
